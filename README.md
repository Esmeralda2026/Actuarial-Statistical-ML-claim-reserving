# Actuarial-Statistical-ML-claim-reserving
R code for actuarial, statistical, and machine learning claim reserving models.
# Claim Reserving Methods and Models in R
This repository contains R code for claim reserving methods and models developed as part of a PhD research study.
## Methods & Models
The code is organized into three R scripts:

1. Actuarial deterministic and stochastic reserving methods: Chain-Ladder (CL), Bornhuetter-Ferguson, Double CL, Bornhuetter Double CL,
   Munich CL, Mack CL, Clark LDF, Clark Cape Cod, Bootstrap CL, Bootstrap Double CL.
   
3. Statistical models: Quasi-Poisson GLM, Tweedie GLM, and LASSO-penalized Poisson regression
   
5. Machine learning models: Decision Tree, Random Forest, and XGBoost

The statistical and machine learning models are evaluated using calendar-based rolling-origin validation.

## Data confidentiality

The analysis is based on aggregated claim data from two insurance companies. The original data are not publicly available due to confidentiality restrictions. The code is provided to document the modelling workflow used in the dissertation.
